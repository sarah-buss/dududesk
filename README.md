# DuduDesk 嘟嘟Desk

DuduDesk -- macOS desktop cat companion

嘟嘟是我两岁半的小猫，她很粘人。这个app的灵感来源于cat gatekeeper和小红书上把它做成app的博主。她/他们的作品都很厉害，但我更想让我最喜欢的小猫出现在我的桌面上，所以就有了这个简陋的app。一些嘟嘟的日常生活照片会在desktop上游走，假装是嘟嘟在玩耍。她还会每五个小时在桌面上的“猫砂盆”文件夹里拉屎。

声明：这个app实际上是claude code全部完成的，我只负责给出指令，不耐烦的时候在床上急得游泳。

Download the latest release and drag DuduDesk.app to your Applications folder.
